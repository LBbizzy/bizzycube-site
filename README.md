# bizzycube-site

Marketing site for BizzyCube — the AI marketing automation agency that runs on the War Room platform.

- **Framework**: Next.js 16 (App Router) + Tailwind 4 + TypeScript
- **Hosting**: Vercel (project: `bizzycube-site`)
- **Domain**: bizzycube.com (GoDaddy registrar)
- **Sister site**: [crestair-site](https://github.com/LBbizzy/crestair-site) (HVAC tenant on same platform)

## Wave roadmap
- **Wave 1** ✅ — 6 hero pages: Home, How it works, Pricing, About, Case studies, Contact
- **Wave 2** — 9 service pages (one per War Room department)
- **Wave 3** — 6 industry pages + 4 conversion pages + DNS flip to bizzycube.com

Built by the BizzyCube War Room AI fleet.
